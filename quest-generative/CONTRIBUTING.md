# Com col·laborar

Gràcies per ajudar a construir Quest Generative. Comença amb una Issue que expliqui el problema, un exemple i el resultat esperat. Abans de canvis grans, acordem el disseny en públic.

1. Crea una branca i limita cada Pull Request a una tasca concreta.
2. Explica què canvia, per què i com ho has verificat. Indica si no has pogut provar a Quest 3S.
3. Afegeix proves quan hi hagi comportament executable: especialment manifests, quotes, descàrregues i recuperació d'errors.
4. No incloguis claus, enregistraments personals, binaris del motor ni recursos sense permís.
5. Identifica autor, font i llicència dels recursos. Les aportacions originals d'aquesta carpeta es publiquen sota MIT; els recursos de tercers han de portar la seva llicència compatible.

Pots aportar codi, traduccions, històries, accessibilitat, proves, models o documentació. Respectem els altres, critiquem les idees amb arguments i ajudem les persones que comencen. Les decisions importants han de quedar documentades.

Primeres tasques: esquema del manifest, servidor simulat, escena base VR i proves de rendiment. Consulta el checklist del README per evitar presentar una funcionalitat prevista com si ja estigués implementada.
